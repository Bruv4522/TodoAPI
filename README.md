This is my first real backend project. I built it completely by myself without AI (except for one boilerplate
/delete endpoint which was basically a copy of the /update endpoint). I used Express, Prisma, lru-cache, and few
other libraries to create this masterpiece. I used PostgreSQL and Supabase for the database but I think this project
is more for learning than hosting it so that database is not going to be used in production. To be honest, this is a
pretty sad CRUD app, but yeah, it has ip-based rate limiting. That is the only feature I added not related to CRUD.
